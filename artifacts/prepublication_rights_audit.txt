PRE-PUBLICATION RIGHTS & LICENSE AUDIT

Dataset slug: quarto-two-model-source-v1
Dataset title: Quarto Two-Model Match Source v1
Intended visibility: Private
Intended license for Quarto-owned software: Apache-2.0
Audit scope: Exact payload in kaggle_dataset_staging/quarto-two-model-source-v1/

FINAL VERDICT: BLOCKED — RIGHTS VERIFICATION REQUIRED

Reason: The payload includes selected FMA metadata-derived feature identifiers
and numeric thresholds in domain_adapters.zip. The upstream FMA project says
its metadata is CC BY 4.0, but the staged payload has no attribution/license
notice identifying that material or the changes made to it. In addition, the
staged payload has no Apache-2.0 license or copyright notice, and several
included project files were untracked in the source checkout, so their
authorship/rights chain cannot be independently established from local Git
history. The owner's stated approval of Apache-2.0 for Quarto's own software
is noted, but does not establish rights to third-party material or unknown
contributors' work.

This is a focused evidence report, not legal advice. It does not assert that a
law has been violated or that publication has occurred.

3. COPYRIGHT, ATTRIBUTION AND PROVENANCE FINDINGS

- No root LICENSE, NOTICE, or COPYRIGHT file was found. None is in the staged
  payload. The only tracked license-like file found elsewhere is for
  jquery-ui, which is not part of this Dataset.
- No SPDX, copyright, or license headers were found in the staged Python
  source. The manifest records a local Git checkout with no configured remote.
- The project owner has stated that Apache-2.0 is approved for Quarto's own
  software. The audit cannot independently verify every contributor's
  ownership or assignment, particularly for files identified as untracked by
  the manifest.
- Kaggle SDK example files are referenced by URL in manifest metadata, but are
  not payload files. The staged Task and adapter use the SDK API; no copied
  example block was identified by inspection. This was not a formal
  similarity search.
- The FMA adapter's source URL is useful provenance but is not a complete
  attribution notice. The FMA upstream README names the dataset authors and
  asks users to cite its paper. A compliant attribution should identify the
  FMA metadata source, link CC BY 4.0, and indicate that feature selection and
  thresholding were performed/changed.
- The Task code and model identifiers refer to Kaggle and model providers;
  that does not include their code, models or service assets in the Dataset.

4. POTENTIAL REDISTRIBUTION CONFLICTS

1. FMA metadata-derived constants have a separate CC BY 4.0 provenance.
   The payload has a source URL but no clear attribution/license notice or
   change statement. CC BY 4.0 permits redistribution when its conditions are
   met; an Apache-only blanket designation would not remove those conditions.
2. The staged payload contains no actual Apache-2.0 license/copyright notice.
   The owner's approval is a relevant authorization statement, but must be
   reflected in the Dataset's license metadata and/or included license file,
   subject to confirming rights in all contributions.
3. Untracked project source has no local Git history to establish authorship.
   The manifest calls out the Task, decision trace, Kaggle adapter and
   tournament harness as untracked at snapshot creation. Their status alone
   does not establish third-party origin, but ownership remains
   UNKNOWN — NEEDS VERIFICATION.
4. No known incompatible third-party code or binary asset was found in the
   payload. Source inspection is not proof of complete provenance or of the
   absence of copied material.

5. FILES THAT MAY BE DISTRIBUTED UNDER APACHE-2.0

The Quarto-authored source files may be distributed under Apache-2.0 if the
project owner controls all relevant rights and contributor provenance is
confirmed. This conditional assessment applies to the Quarto code, not to
FMA-derived metadata or the separately installed Kaggle SDK. The requirements
line is a dependency declaration, not a redistribution of the SDK.

The following are not cleared for an Apache-only designation based on current
payload evidence:
- domain_adapters.zip/domain_adapters/fma_adapter.py feature constants and
  thresholds derived from FMA metadata: retain CC BY 4.0 attribution or
  separately verify/exclude the derived material.
- Any contribution whose author/rights holder cannot be confirmed.

  and owner/slug metadata are supplied at publication; do not treat the

7. LICENSE AND NOTICE REQUIREMENTS

- Include or otherwise clearly attach the Apache License 2.0 and a copyright
  holder notice for Quarto-owned code when granting that license.
- Apache-2.0 does not require inventing a NOTICE file when none is applicable.
  CC BY 4.0 does require appropriate credit, a license link and change
  indication. A NOTICE/CREDITS file is a suitable way to meet that need, but
  should preserve the separate CC BY 4.0 status rather than relicense the FMA
  material as Apache-2.0.
- No FMA audio is included, so track-level artist licenses are not
  redistributed by this payload. The FMA metadata-derived constants still
  require the separate analysis above.

8. AUDIT LIMITS AND PRESERVATION

The audit inspected the manifest, exact staged files, ZIP members, matching
root sources, local license/provenance references, relevant local history,
and the cited upstream FMA and Kaggle license materials. Integrity checks were
read-only and passed. It did not perform a full source-code similarity scan,
resolve the hosted SDK dependency tree, determine copyrightability of factual
statistics, or obtain legal advice. Those limits are material to the verdict.

Git preservation: initial and pre-report status were identical on branch
main; no staged changes were present. Existing modifications and untracked
paths were preserved. The only intended filesystem change for this task is
this report: artifacts/prepublication_rights_audit.txt. No source, tests,
manifest, snapshot payload, or remote resource was modified. No Kaggle
operation, upload, publish, or model inference was performed.
